# Island artwork

`ascent-island.png` is a generated, transparent 1536×1024 illustration for the
minimal desktop entry screen. It is an Ascent-inspired decorative diorama,
not a map model or replay evidence. The file is bundled locally by Vite; it
does not require a network request to an external image host.

Created with the built-in image-generation tool on 2026-11-05 ([exact prompt](ascent-island.prompt.txt)), using the
ValCoach Ascent concept image from this design session as the reference.
The prompt requested a standalone floating Venetian island with terracotta
rooftops, bell tower, courtyard tree and fractured stone base; simplified
architectural shapes, muted peach/sage/lavender tones and transparent space;
no interface, words, characters, weapons or sky. No official map asset was
downloaded or copied into this project.

The island, fragments and shadow are static. `../SovaDrone.tsx` is an original
simplified SVG study of [Sova's Owl Drone](https://wiki.playvalorant.com/en-us/Owl_Drone),
with twin rotors and an angular owl-shaped body, recolored in muted peach and
lavender to blend with the island. No game model,
texture or third-party drone artwork is bundled. `../drone-flight.mjs` provides
decorative flight choreography; it does not model ability range,
duration, visibility or other replay facts.
